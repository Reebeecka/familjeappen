# Familjeappen

En gemensam familjeorganisatör (PWA) för att dela uppgifter, inköp, kalender m.m.

👉 **Börja här:** öppna [PLANERING.md](./PLANERING.md) för steg-för-steg-guiden.

## Snabbstart

```bash
npm install
npm run dev
```

Kräver att `.env.local` fyllts i med Supabase-nycklar (se PLANERING.md).
